## 🎯 Executive Summary

The **Diabetes Prediction Web Application** represents a state-of-the-art AI diagnostic system engineered to revolutionize early diabetes detection through three specialized deep learning models. This comprehensive platform combines medical expertise with cutting-edge machine learning to deliver accurate, accessible, and actionable diabetes risk assessments.

## 🚀 Quick Installation Guide

### Prerequisites Checklist
- ✅ Python 3.8 or higher
- ✅ 4GB RAM (8GB recommended)
- ✅ 2GB free disk space
- ✅ Stable internet connection
- ✅ Modern web browser

### One-Command Setup

```bash
# Clone and setup in one command
git clone https://github.com/ashrafaliqhtan/Diabetespredictionapp.git && \
cd Diabetespredictionapp && \
python -m venv venv && \
source venv/bin/activate && \
pip install -r requirements.txt && \
python run.py
```

### Manual Installation Steps

<details>
<summary><strong>Detailed Step-by-Step Guide</strong></summary>

1. **Clone the Repository**
```bash
git clone https://github.com/ashrafaliqhtan/Diabetespredictionapp.git
cd Diabetespredictionapp
```

2. **Create Virtual Environment**
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate
```

3. **Install Dependencies**
```bash
pip install -r requirements.txt
```

4. **Launch Application**
```bash
python run.py
```

5. **Access Application**
Open browser and navigate to: `http://localhost:5000`

</details>

## 🔬 Model Specifications

### Symptoms-Based Model
<div class="model-spec">
  <strong>Input Features (15):</strong> Age, Gender, 13 clinical symptoms<br>
  <strong>Architecture:</strong> DNN with 16-8-1 neuron configuration<br>
  <strong>Activation:</strong> ReLU (hidden layers), Sigmoid (output)<br>
  <strong>Optimizer:</strong> Adam with learning rate 0.001<br>
  <strong>Training:</strong> 100 epochs with early stopping
</div>

### Laboratory Measurements Model
<div class="model-spec">
  <strong>Dataset:</strong> PIMA Indian Diabetes Dataset (768 samples)<br>
  <strong>Features:</strong> 8 clinical measurements<br>
  <strong>Architecture:</strong> 128-64-32-1 DNN with Dropout (0.3)<br>
  <strong>Performance:</strong> 79.27% accuracy with strong clinical correlation
</div>

### Lifestyle Factors Model
<div class="model-spec highlight">
  <strong>Dataset:</strong> 100,000 entries with 9 features<br>
  <strong>Architecture:</strong> 64-128-64-1 DNN with Dropout (0.5) + L2 Regularization<br>
  <strong>Performance:</strong> 97.35% accuracy, 100% precision<br>
  <strong>Innovation:</strong> Superior predictive power for preventive healthcare
</div>

<script>
// Smooth scrolling for anchor links
document.querySelectorAll('a[href^="#"]').forEach(anchor => {
  anchor.addEventListener('click', function (e) {
    e.preventDefault();
    const targetId = this.getAttribute('href');
    if(targetId === '#') return;
    
    const targetElement = document.querySelector(targetId);
    if(targetElement) {
      window.scrollTo({
        top: targetElement.offsetTop - 20,
        behavior: 'smooth'
      });
    }
  });
});

// Lazy loading for images
document.addEventListener('DOMContentLoaded', function() {
  const images = document.querySelectorAll('img[loading="lazy"]');
  
  const imageObserver = new IntersectionObserver((entries, observer) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        const img = entry.target;
        img.src = img.dataset.src || img.src;
        img.classList.add('loaded');
        observer.unobserve(img);
      }
    });
  });
  
  images.forEach(img => imageObserver.observe(img));
});

// Add hover effect to metric cards
document.querySelectorAll('.metric-card').forEach(card => {
  card.addEventListener('mouseenter', function() {
    this.style.transform = 'scale(1.05)';
  });
  
  card.addEventListener('mouseleave', function() {
    this.style.transform = 'scale(1)';
  });
});

// Highlight current section in view
const sections = document.querySelectorAll('h2, h3, h4');
const navLinks = document.querySelectorAll('a[href^="#"]');

window.addEventListener('scroll', function() {
  let current = '';
  
  sections.forEach(section => {
    const sectionTop = section.offsetTop;
    const sectionHeight = section.clientHeight;
    if (scrollY >= sectionTop - 60) {
      current = section.getAttribute('id');
    }
  });
  
  navLinks.forEach(link => {
    link.classList.remove('active');
    if (link.getAttribute('href') === `#${current}`) {
      link.classList.add('active');
    }
  });
});
</script>
